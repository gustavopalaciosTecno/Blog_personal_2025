Portafolio Blog Personal
Un sitio web profesional para mostrar tu portafolio, experiencia, estudios y artículos de blog. Esta página web está desarrollada con HTML, CSS y JavaScript puro, sin dependencias externas.

Características
✅ Diseño completamente responsive - Se adapta a dispositivos móviles, tablets y desktop

✅ Secciones completas:

Inicio con carrusel de imágenes interactivo

Sobre mí con habilidades y porcentajes

Portafolio con filtro por categorías

Estudios con línea de tiempo visual

Blog con artículos destacados

Contacto con formulario funcional

✅ Carrusel de imágenes con:

Navegación manual (flechas y puntos)

Transición automática cada 5 segundos

Pausa al interactuar

Leyendas personalizables

✅ Efectos visuales:

Animaciones suaves

Transiciones CSS

Hover effects

Scroll suave

✅ Navegación inteligente:

Menú fijo en la parte superior

Indicador de sección activa

Menú hamburguesa en móviles

Scroll suave entre secciones

Estructura del Proyecto
El proyecto está contenido en un solo archivo HTML que incluye:

HTML: Estructura semántica del contenido

CSS: Estilos en el mismo documento (embedded)

JavaScript: Funcionalidades interactivas
